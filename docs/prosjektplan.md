## 6. Arbeidsrutine

1. Opprett en Issue med mål og ferdigkriterier.
2. Arbeid i en egen branch.
3. Commit og push med forståelige meldinger.
4. Opprett pull request og la partneren gjennomgå endringen.
5. Kontroller CI før fletting og utrulling.
6. Oppdater relevant dokumentasjon og lukk oppgaven.
